● 桌面应用模式
WSL 里的应用用不了 Windows 输入法。 WSLg 只把画面和按键转发给 Linux，Windows 的中文输入法不会跟着进去，所以 Linux 应用必须在 Linux 里自带一套输入法。 当前 WSL 内没有检测到 fcitx5，点右边装一个（拼音），装完按 Ctrl+空格 切中英文。

已安装的 GUI 应用

常用应用 · 一键安装

以 root 身份运行 apt-get install（无需输入密码），安装输出实时显示在下方终端里，装完自动重扫。绿色 ✓ 表示该包已装好，点一下可重装。

快捷键：Ctrl+1 启动台 · Ctrl+2 一键安装 · Ctrl+F 搜索应用 · Esc 收起终端
应用窗口由 WSLg 渲染，属于 WSL 内的程序；关闭应用后终端会显示退出码。所有功能都在本应用内完成，不依赖浏览器、不占用网络端口。
